To sync: play the video and press "Bar 1 starts now" on the first downbeat of bar 1, or type the time. Then set a later bar number, pause the video exactly on that bar's downbeat, and press the button again to fit the tempo. Nudge with the buttons while it plays. The play button, bar clicks, and loops all control the video. Each song in your library (and each demo) remembers its own video and sync. To remove a video, clear the link and press Load video.

          Write one line per hand or voice, starting with RH: or LH: (any name works; names starting with L go on the bass staff). End each bar with |. Notes look like C4, F#3 or Bb5 (C4 is middle C); chords go in brackets like [C4 E4 G4]; r is a rest. Add a length after a slash: /1 whole, /2 half, /4 quarter, /8, /16, /32, a dot for dotted (/4.) and t for triplets (/8t). A length carries on until you change it. Tie into the next note with ~ (C4~ or [C4~ E4]). Comments start with %.

          ABC notation, the standard plain-text format for sheet music. Start with the fields X:1, T: (title), M: (time, like 4/4), L: (default note length, like 1/8) and K: (key, like G or Am). For piano, add V:RH clef=treble and V:LH clef=bass, then start each line of music with [V:RH] or [V:LH]. Notes: C D E F G A B is the octave from middle C, c d e ... the octave above; add ' to go up an octave and , to go down. ^ is sharp, _ is flat, = is natural. A number after a note multiplies its length (C2), a slash divides it (C/). Chords: [CEG]. Rest: z. Tie: C-C. Bars: |. Comments start with %.

          Paste ASCII tab, one line per string with the highest string on top. Every column is one time slot, and "Columns per beat" sets how many columns make a beat. Mark bars with |. Supported marks: frets 0 to 24, x for muted notes, and h, p, /, \, b, ~ as technique hints. The sheet updates as you type.
